# Sollang repository instructions for AI Agents

Before reading or changing Sollang code, read `docs/AI_AGENT_GUIDE.md` completely
and follow its source-of-truth order, syntax rules, root-cause-only policy, and
verification ladder.

`docs/AI_AGENT_GUIDE.md` is the canonical Agent coding guide. Any change to
preferred grammar, semantics, ownership, effects, CLI behavior, target
capabilities, standard-library vocabulary, user examples, browser samples, or
required verification must review and update that guide in the same change.
Do not duplicate the guide here.
